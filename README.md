# Data Detective

A Python application for inspecting CSV datasets and identifying
potential data quality issues.

## Current Features

- Read CSV files
- Count records and columns
- Display column names
- Preview the first three records
- Handle missing CSV files

## How to Run

1. Install Python 3.
2. Clone the repository.
3. Open the project directory.
4. Run the program:

   python main.py
